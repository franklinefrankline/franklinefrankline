Smart Nail Health Monitoring System

About the Project

The Smart Nail Health Monitoring System is an intelligent healthcare application developed to analyze nail health using advanced digital image processing techniques. The system allows users to upload or capture a nail image and automatically evaluates the condition of the nail based on various image features.

The uploaded image undergoes several image processing operations, including image resizing, center cropping, grayscale conversion, RGB color analysis, texture analysis, contrast detection, edge detection, and feature extraction. Based on these features, the system calculates the nail moisture level, nail health score, and determines the risk level.

The application provides users with detailed health reports, personalized recommendations, historical report tracking, and downloadable PDF reports. The system is designed to assist users in monitoring their nail health and identifying possible abnormalities such as dryness, fungal infections, discoloration, and nail damage.

Project Features

  • User Registration and Login
  • Secure Image Upload
  • Digital Image Processing
  • Moisture Level Detection
  • Nail Health Score Calculation
  • Risk Classification (Low, Medium, High)
  • Personalized Recommendations
  • Dashboard with Report History
  • PDF Report Generation

Project Objective

To develop a smart web-based healthcare application capable of automatically analyzing nail images using image processing techniques and providing accurate moisture level estimation, nail health scoring, risk classification, and personalized healthcare recommendations.
