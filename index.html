Smart Nail Health Monitoring System

The Smart Nail Health Monitoring System is an intelligent healthcare application that analyzes nail health using digital image processing techniques. Users can upload or capture a nail image to automatically detect nail moisture level, health score, and risk status. The system extracts color, texture, contrast, and edge features to generate accurate health reports and personalized recommendations.
